# 🎀 Simon-Says-Game-JS

This repository contains a browser-based **Simon Says memory game**, built 
using HTML, CSS, and JavaScript. This project was built as part of my 
JavaScript practice, focused on DOM manipulation, event handling, and 
game logic.

## How It Works
- Press any key to start the game
- The game flashes a random sequence of colors
- The player must repeat the sequence by clicking the buttons in the same order
- Each correct round increases the level and adds a new color to the sequence
- A wrong click ends the game and displays the final score

## Features
- Randomized color sequence generation
- Level tracking system
- Visual flash animation on button press
- Game-over feedback with background color flash
- Game resets automatically after a wrong move

## Technologies Used
- HTML5
- CSS3
- JavaScript (DOM manipulation, event listeners, array logic)
